# 내가 나의 롤모델이 되는 프로젝트

1% HABIT$, 캘리미시의 '내 삶의 주인이 되는 2주(10일)' 프로그램 1일차를 무료로 체험해 볼 수 있는 플러그인입니다.

## 들어 있는 것

| 스킬 | 언제 쓰나요 | 무엇을 하나요 |
|------|-------------|---------------|
| 1일차 · 나를 찾는 코치 (`my-role-model-day1`) | 프로그램 첫날 | 한 번에 한 질문씩 대화하며 지금의 롤모델, 내가 행복할 때, 나의 가치, 내가 정말 살고 싶은 삶을 찾고, '나의 롤모델 카드' 한 장으로 정리합니다. |

## 사용 방법

1. 플러그인을 설치합니다.
2. 새 대화에서 "1일차 시작할게요" 또는 "나의 롤모델을 찾고 싶어요"라고 말합니다.
3. 질문에 편하게 답합니다. 불편한 질문은 언제든 "패스"라고 하면 됩니다.
4. 마지막에 받은 '1일차 나의 롤모델 카드'를 저장해 두세요. 10일차에 다시 꺼내 봅니다.

## 알아 두실 것

- 1일차 대화 하나를 진행합니다. 2~10일차는 수업에서 함께합니다.
- 대화 내용은 다음 대화로 이어지지 않으니, 카드는 직접 저장해 주세요.
- 상담이나 치료가 아닌 성장 프로그램입니다.
